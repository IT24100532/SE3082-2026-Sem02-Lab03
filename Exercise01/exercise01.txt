Exercise 1: serial Pi
Run on: Debian Linux container (Docker), gcc 14.2, 8 logical cpus. Build: make   Run: make run

pi/4 = integral of 1/(1+x^2) from 0 to 1 ~= (1/N) * sum_{i=1..N} 1 / (1 + ((i - 0.5)/N)^2)
N = 100,000,000

Compile and run:  gcc -fopenmp -O2 pi_serial.c -o pi_serial && ./pi_serial
(-fopenmp is only needed for the omp_get_wtime() timer.)

Output:
serial:   pi = 3.141592653590426, error = 6.33e-13, time = 0.099066 s

The answer is correct to 12 decimal places.
